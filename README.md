## ¿Por qué una carta digital para un restaurante?

- **Siempre actualizada** — cambia precios o platos en segundos, sin imprimir nada
- **Accesible desde cualquier dispositivo** — móvil, tablet u ordenador
- **Mejor experiencia para el cliente** — navegación rápida por secciones, alérgenos visibles
- **Sin costes de impresión** — olvídate de plastificar y reponer cartas físicas
- **Posicionamiento online** — presencia en Google para clientes que buscan el restaurante
